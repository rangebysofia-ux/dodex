# 6 Balansmall och nyckeltal

Ett schema ska vara i balans mellan behov, arbetsmiljö, budget och kvalitet. Inget perspektiv får styra ensamt. Jämför alltid alternativ på de här måtten, sida vid sida, och markera vilket alternativ som är bäst per rad.

| Perspektiv | Mått | Bäst |
|---|---|---|
| Behov | Täckning av behovet (andel bemannade pass per dag och dygnsdel) | högt |
| | Vakanta pass | lågt |
| | Vakanser vid klockslag (om behov per klockslag finns) | lågt |
| Arbetsmiljö | Brott mot hårda regler | lågt (ska vara 0) |
| | Mjuka regler som inte nås | lågt |
| | Längsta arbetsblock; dagar i följd över 4 | lågt |
| | Flest kvällar i rad, flest nätter i rad | lågt |
| | Brutna önskemål | lågt |
| Budget | Planerade timmar per vecka | visas |
| | Över budget, timmar per vecka | lågt |
| | Resurstid (överbemanning), timmar per vecka | visas |
| | Personalkostnad (med timkostnad) | lågt |
| Kvalitet | Resurspass jämnt över veckodagarna (flest minus minst) | lågt |
| | Resurstid på kväll, andel (varken bara dag eller bara kväll) | visas |
| | Rättvisa: skillnad i andel kvällar mellan dem som arbetar dag och kväll | lågt |
| | Kompetensvakanser (pass där en krävd kompetens saknas) | lågt |
| | Aktiviteter som saknar deltagare | lågt |

- Rött bara för brott mot hårda regler, vakanser och tid över budget.
- Övriga mått har inga gränsvärden; de jämförs mellan alternativen.

## Nyckeltal per person

Pass och timmar mot kontrakt, kvällspass, arbetade helger, längsta block, veckor utan blandning av dag och kväll, extra helgpass.

## Handlingsplan

När analysen visar brister: en tabell med problem, åtgärd, ansvarig, klart senast och hur det följs upp. Åtgärder som ändrar en lokal regel eller varannan helg kräver verksamhetens beslut och ibland samverkan; skriv det.
